# Media-Zefanya v3 (Taman)

Aplikasi manajemen fasilitas taman kota/florikultura yang terhubung ke Supabase (`dytcoemthbngxoamoetr`).

## Fitur Utama
- CRUD data tanaman dan area taman.
- Pencarian dan pengurutan kondisi taman.
- Mode verifikasi guru (password: `zefanya123`).
