## 🌟 Fitur-Fitur Seru di Dalamnya

- 🌻 **Catat Hasil Pengamatan Taman** - Masukin nama tanaman, lokasi, dan hasil pengamatan indra penglihatanmu!
- 🔍 **Pencarian Kilat** - Ketik nama bunga atau tanaman yang kamu amati, langsung ketemu!
- 🔐 **Mode Guru (Secret Password)** - Halaman khusus guru dengan sandi `zefanya123` untuk memverifikasi nilai pengamatan kelompok.
- ☁️ **Nyambung ke Supabase** - Data aman tersimpan di cloud pada tabel `taman`.
